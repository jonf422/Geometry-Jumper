# Geometry-Jumper

Geometry Jumper is a game inspired by geometry dash. The player has to use their 2 jumps to stay on the red platforms, and get the highest score. The game ends when you touch the ground.

This game is built in C++.

All fonts, shaders, shapes, util, and main.cpp were authored by Lisa Dion and given to me as starter code. Lisa also provided starter code for Engine.h and Engine.cpp, but both were then modified by me.
